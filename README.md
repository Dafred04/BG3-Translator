# BG3 Mod Translator

Я большой фанат модов для Baldur's Gate 3, но меня давно бесит, что почти все моды выходят только на английском. Хороших переводов ждать приходится неделями, а иногда их просто не делают. Поэтому я написал себе инструмент, который переводит моды сам — и решил, что он пригодится и другим.

Скачал мод с Nexus → кидаешь `.pak` или `.zip` в программу → жмёшь «Translate all» → получаешь готовый перевод. Дальше только вычитать спорные места и экспортировать обратно в `.pak` для BG3MM. Всё.

## Что умеет

- **Открывает всё, что связано с BG3-модами**: `.pak` (LSPK v18 — LZ4/Zlib/Zstd), `.zip`, бинарные `.loca`, `.xml` или распакованную папку. Формат pak я переписал сам по спецификации LSLib, никакого Divine.exe не нужно. Название, автора и версию мода берёт из `meta.lsx`; если в моде уже есть перевод на нужный язык — подхватывает его.
- **Редактор переводов** — таблица «оригинал → перевод» и панель строки справа: подсветка тегов, счётчик символов, подсказка из словаря, комментарий. Фильтры (непереведённые / на проверке / с ошибками / с предупреждениями), «Найти и заменить» (Ctrl+H) и отмена правок (Ctrl+Shift+Z).
- **Автоперевод**: Google Translate работает вообще без ключа — для пробы самое то. Для качества — Gemini или любой OpenAI-совместимый API (DeepSeek, OpenAI, OpenRouter, локальные Ollama/LM Studio) в «Настройках». Перед большим прогоном показывается оценка: сколько строк, запросов и времени. Ключ API хранится в системном хранилище (keyring).
- **Словарь переводов** — SQLite-память: всё, что вы перевели один раз, переиспользуется в следующих модах. «Fire Bolt» второй раз уже не уходит в API, а берётся из словаря. Ручные правки без ошибок запоминаются как проверенные. Есть глоссарий терминов (их ИИ обязан переводить одинаково) и импорт/экспорт CSV.
- **Защита от битого текста** — теги и плейсхолдеры (`<LSTag>…</LSTag>`, `<br>`, `&entity;`, `{0}`, `[1]`) перед отправкой ИИ заменяются метками и возвращаются на место; результат проверяется ещё раз. Текст внутри `<LSTag>` переводится, сам тег остаётся нетронутым. Строки с проблемами получают пометку «На проверке» или «Ошибка».
- **Экспорт** в готовый `.pak` (отдельный мод-перевод с `meta.lsx` и зависимостью от оригинала), в `.loca` или `.xml`. Кнопка «Установить в папку модов BG3» кладёт пакет прямо в `%LOCALAPPDATA%\Larian Studios\Baldur's Gate 3\Mods`. Перед экспортом — отчёт: сколько переведено и сколько строк с ошибками.
- **Проекты** сохраняются сами (и по Ctrl+S); на главной есть список недавних. Для автоматизации есть консольная команда: `python -m bg3_translator.cli translate <мод> --to ru` (из папки `src`).
- Версия локализации при экспорте никогда не опускается ниже исходной (иначе игра может показать английский вместо перевода).

## Запуск

Нужен Python 3.10+.

```bash
git clone https://github.com/Dafred04/BG3-Mod-Translator.git
cd BG3-Mod-Translator
pip install -r requirements.txt
python main.py
```

## Тесты

Всё проверяется офлайн (без сети и без GPU). Проще всего запускать всё сразу:

```bash
pip install pytest
python -m pytest tests
```

Старые smoke-тесты по-прежнему запускаются и по одному (`python tests\test_core.py` и т. д.). Наборы `tests/test_v2_*.py` покрывают новое ядро: pak, `.loca`, `meta.lsx`, импорт, экспорт, провайдеры, движок, логику интерфейса.

## Как это устроено

```
main.py                     — точка входа
src/bg3_translator/
  config.py                 — пути, настройки, языки
  models/                   — сущности проекта перевода
  core/
    pak.py                  # LSPK v18 чтение/запись
    loca.py, locaxml.py     # бинарный .loca и XML локализации
    meta.py                 # meta.lsx мода-перевода
    validation.py           # плейсхолдеры, защита тегов, QA
    languages.py            # языки и папки BG3
  services/
    importer.py, exporter.py  # мод → проект, проект → .pak/.loca/.xml
    dictionary.py           # память переводов и глоссарий (SQLite)
    providers.py            # Gemini, OpenAI-compatible, Google Free
    engine.py               # словарь → провайдер → проверка, пакеты и потоки
    keystore.py, prefs.py   # ключи API и недавние проекты
  ui/                       # PySide6, светлая/тёмная тема
    logic.py                # логика интерфейса без Qt (тестируется отдельно)
tests/                      # smoke-тесты
```

## Пара честных оговорок

- Google Translate тут через неофициальный endpoint — для серьёзной работы настройте свой API-ключ (DeepSeek стоит копейки).
- AI-перевод закрывает механику отлично, но диалоги всё равно стоит вычитать глазами — машина пока плохо чувствует подтекст и юмор.
- `.pak`-формат реализован по спецификации LSLib (спасибо Norbyte!) — без него ничего бы не было. Baldur's Gate 3 — товарный знак Larian Studios, проект с ними не связан.
